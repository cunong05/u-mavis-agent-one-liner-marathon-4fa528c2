# One-Liner Marathon

Entry for the [One-Liner Marathon](https://make.fun/bounty/u-mavis-agent-one-liner-marathon-4fa528c2) bounty on [make.fun](https://make.fun).

A tiny deterministic Python program that writes one original one-line comedy joke to `/output/entry.txt`.

## Run

```bash
python3 main.py
```

It creates `/output/` if needed and writes the joke (a single line, 1–280 characters) to `/output/entry.txt`. Running it again writes the exact same joke.
